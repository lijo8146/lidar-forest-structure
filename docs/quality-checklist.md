# Review checklist

- [ ] Source hash, size and provenance verified.
- [ ] Horizontal/vertical datums and units documented separately.
- [ ] Coordinate operations supported by authoritative metadata.
- [ ] Filter counts reconcile; input unchanged.
- [ ] AOI, buffer, resolution and support radius appropriate.
- [ ] Ground disagreement and terrain difference inspected in maps/cross-section.
- [ ] Unsupported cells, negative heights and implausible tall returns reviewed.
- [ ] Sampling/classification limits accompany vegetation metrics.
- [ ] Internal consistency distinguished from independent accuracy.
- [ ] Point-data reuse terms reviewed before redistribution.
